# Korean Food Image Classifier

## Project Overview

The Korean Food Image Classifier is a machine learning and Flask-based web application that identifies Korean food items from images and provides nutritional and health-related information. The model classifies six popular Korean dishes using a trained deep learning model.

## Features

* Upload a food image through a web interface
* Classifies the image into one of six Korean food categories
* Displays prediction confidence
* Shows ingredients and food description
* Provides nutrition, health benefits, side effects, and the best way for Indians to consume the food

## Food Categories

* Bibimbap
* Bulgogi
* Japchae
* Kimbap
* Kimchi
* Tteokbokki

## Installation

1. Clone the repository:
   git clone https://github.com/yourusername/Korean-Food-Image-Classifier.git

2. Install dependencies:
   pip install -r requirements.txt

3. Run the Flask application:
   python app.py

4. Open the browser and visit:
   http://127.0.0.1:5000/

## Output

The application predicts the food item from the uploaded image and displays confidence, ingredients, description, and health-related information.
